# شیشهٔ مایع — Liquid Glass

یک کیت کاملِ **شیشهٔ مایع** برای React که همهٔ شیشه‌هایش را یک رندرر WebGL2 می‌کشد: هر کنترل مثل یک عدسی واقعی است که صفحهٔ پشتش را می‌شکند، لبه‌اش رنگ همسایه‌ها را بازمی‌تاباند و با فنر و لرزش طبیعی زیر اشاره‌گر متورم می‌شود.

- منبع: [bilalgursen/liquid-glass](https://github.com/bilalgursen/liquid-glass)
- لایسنس: **MIT** — برخلاف بیشتر آیتم‌های این گنجینه، این یکی اجازهٔ بازنشر دارد
- تاریخ جمع‌آوری: ۲۴ نوامبر ۲۰۲۶
- کد اصلی دست‌نخورده: [src/liquid-glass/](src/) · لایسنس: [LICENSE](LICENSE)

## پنج کنش، پنج آیتم

هر کامپوننت کیت فقط یک کار می‌کند و نامش همان کار است. پنج‌تایی که اینجا دموی زنده دارند:

| کنش | آیتم | چه می‌کند |
| --- | --- | --- |
| Press | [press-button/](press-button/) · `GlassButton` | دکمهٔ شیشه‌ای شفاف یا رنگی که زیر اشاره‌گر متورم می‌شود؛ نگهش داری و بکشی، مثل ژل دنبال دست می‌آید |
| Merge | [merge-action-button/](merge-action-button/) · `GlassActionButton` | دکمهٔ کنش ناهمگام که فلشش یک قطرهٔ جدا است و با فشار در بدنه ذوب می‌شود و تا پایان کار یکی می‌ماند |
| Hold | [hold-card/](hold-card/) · `GlassCard` | کارت شیشه‌ای که محتوا را نگه می‌دارد؛ لبه‌اش پشتِ متحرک را به سمت مرکز می‌کشد و سطحش مات می‌کند |
| Share | [share-button-group/](share-button-group/) · `GlassButtonGroup` | چند کنش در یک بدنهٔ شیشه با جداکننده؛ کل بدنه با اشاره‌گر متورم می‌شود |
| Flow | [flow-badge/](flow-badge/) · `GlassBadge` | نشان کوچک رنگی که متن از میان شیشه‌اش می‌گذرد و لبه، حروف را می‌شکند |

بقیهٔ کیت — تب‌های عدسی‌دار (`GlassTabs`)، اسلاید-تأیید (`GlassSlideToConfirm`)، منو، دراپ‌داون، پاپ‌اور و سلکت (نیازمند `@ui-sdk`)، و کنترل‌های `three.js` (سوییچ، چک‌باکس، اسلایدر) — کدشان در [src/liquid-glass/](src/) هست ولی دموی بدون build ندارند.

## چطور اجرا می‌شود

هر آیتم یک `demo.html` مستقل دارد. بازش کنید — بدون build، بدون `npm`، بدون اینترنت:

```bash
python -m http.server 4173   # از ریشهٔ ریپو، و بعد http://localhost:4173
```

یا اینکه فایل را مستقیم در مرورگر باز کنید. سه فایل مشترک کنار دموها:

| فایل | نقش |
| --- | --- |
| `liquid-glass.js` | ران‌تایم جاوااسکریپتِ ساده. `engine.ts` و `dom-snapshot.ts` عیناً از کد اصلی (فقط بدون تایپ‌های TypeScript) و بدنهٔ افکتِ `glass-layer.tsx` و `glass-badge.tsx` هم عیناً از همان فایل‌ها برداشته شده؛ فقط React با فراخوانی مستقیم DOM جایگزین شده. هیچ‌چیز بازنویسی نشده. |
| `glass.css` | اسکلت مشترک دموها: صحنه، تایپوگرافی و قطعه‌های پس‌زمینه (دیسک، پنل، شبکهٔ خطوط) |
| `src/liquid-glass/` | کیت اصلی، دست‌نخورده، برای مرجع و کپی در پروژهٔ خودتان |
| `tools/build-runtime.mjs` | همان اسکریپتی که `liquid-glass.js` را از `src/` می‌سازد: با `node glass/tools/build-runtime.mjs` دوباره تولید می‌شود (خروجی بایت‌به‌بایت یکسان است) |

ران‌تایم سه تابع دارد: `LiquidGlass.layerFor(host, props)` (معادل `<GlassLayer/>`)، `LiquidGlass.badgeFor(host, props)` (معادل `<GlassBadge/>`) و `LiquidGlass.injectStyles()` (همان CSS ای که کیت لازم دارد).

## نکته‌هایی که به کار می‌آیند

- **پس‌زمینهٔ دموها عمداً از رنگ تخت و المان واقعی ساخته شده.** شیشه صفحهٔ پشتش را با یک پیمایش DOM عکس‌برداری می‌کند؛ گرادیان، ماسک، فیلتر CSS و شبه‌عنصرها (`::before/::after`) برایش دیده نمی‌شوند و در شیشه ظاهر نمی‌شوند.
- **`data-glass-ready`:** تا اولین فریمِ شیشه، خودِ المان با CSS رنگ و حاشیه و سایه دارد؛ بعد از آن شیشه این‌ها را می‌کشد و کلاس CSS کنار می‌رود. بدون WebGL2 همین ظاهر CSS باقی می‌ماند، پس چیزی نمی‌شکند.
- **`data-glass-tone`** رنگ روشن/تیرهٔ شیشه را به متن می‌دهد تا روی هر پس‌زمینه‌ای خوانا بماند.
- همهٔ کامپوننت‌ها یک رندرر مشترک و یک شیدر دارند؛ فیزیک حرکت با فنر است (`SPRINGS`) و برای `prefers-reduced-motion` ساکن می‌شوند.
- عددهای شیدر و فنرها سلیقه‌ای نیستند؛ ظاهر کیت را تعریف می‌کنند. اگر تغییری می‌خواهید، از `optics` استفاده کنید، نه از دست‌زدن به ران‌تایم.
