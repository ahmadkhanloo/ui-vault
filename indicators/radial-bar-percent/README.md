# نوار پیشرفت شعاعی — Radial Bar Percent

نسخه‌ی شعاعی نوار پیشرفت؛ میله‌ای گرد که همراه شمارنده‌ی درصد دور مرکز پر می‌شود.

از بخش کامپوننت‌های رایگان [Quix Studio](https://quixstudio.net/free/components) (۲۰ نوامبر ۲۰۲۶) جمع‌آوری شده است. کد با دکمه‌ی «Copy code» همان کارت کپی و عیناً در `snippet.html` ذخیره شده؛ `component.html` همین کد است داخل یک صفحه‌ی حداقلی برای دیدن زنده.

## فایل‌ها

| فایل | توضیح |
| --- | --- |
| `snippet.html` | کد اصلی کپی‌شده از سایت — بدون تغییر |
| `component.html` | پیش‌نمایش زنده — در مرورگر باز کنید |
| `card.png` | اسکرین‌شات زنده از پیش‌نمایش |

## استفاده

عنصر `lp-loader` را در صفحه بگذارید و اسکریپت `snippet.html` را کنارش قرار دهید. اتریبیوت‌های قابل تنظیم: `type`، `size`، `color`، `speed`، `value`، `text` و `paused` (مثلاً `color` برای رنگ تم و `value` برای درصد ثابت).

> **حقوق:** طبق اعلام Quix Studio، این کامپوننت‌های رایگان برای «استفاده‌ی شخصی و تجاری» آزادند؛ این کپی با ذکر منبع برای مرجع شخصی در این ریپو نگه‌داری می‌شود.
